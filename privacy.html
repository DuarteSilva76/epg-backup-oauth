Privacy Policy

Last updated: September 18, 2026

EPG Backup is a private application used by its owner to back up personal server configuration files to Google Drive.

Google Drive Access

The application accesses Google Drive only to create, upload, manage, and delete backup files belonging to the application owner.

Data Collection

EPG Backup does not collect, sell, share, or distribute personal information to third parties.

Data Storage

Backup files are stored only in the Google Drive account authorized by the application owner.

Third Parties

No user data is sold or shared with advertisers or other third parties.

Contact

For questions regarding this privacy policy, contact the application owner.
